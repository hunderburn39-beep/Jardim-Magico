# Pantanal Web 2.06 — reconstrução experimental

Versão HTML autónoma do Pantanal Caça Níquel, feita a partir do APK fornecido pelo utilizador, com gráficos e sons incorporados no ficheiro index.html.

Jogar: https://hunderburn39-beep.github.io/Jardim-Magico/Pantanal/

Use o telemóvel na horizontal para uma experiência mais próxima do original 800×480.

Menu de administração: engrenagem no ecrã inicial. PIN provisório: 12345. Dados e histórico são locais ao navegador, sem servidor ou dinheiro real.

**Nota de fidelidade:** a matemática, o RNG, a frequência dos bónus e as rotinas administrativas originais não estão integralmente portados nem validados. Os prémios e o gerador desta versão são reconstruções experimentais. As configurações recuperadas do APK ainda não controlam probabilidades.

**Direitos:** os materiais gráficos e sonoros foram extraídos do APK entregue para análise. A redistribuição pública deve ter autorização dos titulares dos direitos.
